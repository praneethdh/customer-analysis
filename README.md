# Customer Behavior & Segmentation Analysis

## About The Project

An exploratory data analysis project examining e-commerce customer data to understand behavior, preferences, and purchasing patterns. The analysis identifies key trends to help businesses make more informed, data-driven decisions around customer engagement and strategy.

## Dataset

E-commerce customer dataset

## Analysis Approach

- Data cleaning and preprocessing
- Exploratory data analysis using Seaborn and Matplotlib

## Tech Stack

- **Language:** Python
- **Libraries:** Pandas, NumPy, Seaborn, Matplotlib
- **Environment:** Jupyter Notebook
